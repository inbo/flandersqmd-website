# Html elements

## Fold and unfold

In comparison with books, websites in html format allow some dynamic elements, such as folding and unfolding text parts.

<details>

<summary>Unfold this text line to read more information.</summary>

To allow to fold and unfold text, it is important that all text is written between a `<details>` and a `</details>` html tag.
The text that stays visible, should additionally be between a `<summary>` and a `</summary>` html tag.
The text that disappears, is placed below this visible text, but before the final `</details>` tag.

</details>
